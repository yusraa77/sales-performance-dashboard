# Sales Performance Dashboard

An interactive sales dashboard developed using Microsoft Power BI to analyze sales performance across products, countries, and time periods.

## Project Overview

This project explores the Financial Sample dataset using interactive visualizations to present sales trends, compare product performance, and examine sales across different countries.

## Dashboard Features

- **Total Sales:** Displays the overall sales amount.
- **Total Profit:** Displays the overall profit amount.
- **Units Sold:** Shows the total number of units sold.
- **Sales by Product:** Compares sales across different products.
- **Sales by Country:** Compares sales across countries.
- **Monthly Sales Trend:** Visualizes changes in sales over time.
- **Product Sales Distribution:** Shows each product's percentage of total sales.
- **Interactive Country Filter:** Allows users to filter the dashboard by country.

## Tools and Skills

- Microsoft Power BI
- Data Visualization
- Interactive Dashboard Design
- Sales Data Analysis

## Dataset

This project uses the sample Financial Sample dataset provided for learning and practice. The results are based on sample data and do not represent actual company performance.
